

# Python - Control Flow


This directory contains scripts that practice conditional statements in Python


## Files


- `positive_or_negative.py`: assigns a random integer between -10 and 10 to `number`  and prints whether it is positive, zero, or negative.


## Usage

./positive_or_negative.py


## Requirements


- Ubuntu 20.04 LTS

- Python 3.8.x

- PEP8 compliant (pycodestyle 2.7x)
